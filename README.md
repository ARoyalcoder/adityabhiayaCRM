# Pawan Putra Business OS

A modular business operating system for a multi-service company (CCTV & Security, Digital Marketing, Interior Design, Architecture & Tech, Real Estate, Solar, IT Support), covering the lifecycle from lead to renewal and cross-sell.

Stack: React + TypeScript + Vite frontend, Java 21 + Spring Boot backend, PostgreSQL, Redis, Docker, Nginx. Architecture: modular monolith.

Architecture documentation lives in `docs/architecture/`.
